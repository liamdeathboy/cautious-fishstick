Instructions

Fill every empty square so that each row, each column, and each of the nine three-by-three boxes contains the digits 1 through 9 exactly once. Click or tap a blank square to select it and type a number to place it. The 35 digits printed at the start are fixed clues and cannot be edited, so the puzzle always has the same solution.

Use the 'how am I going?' button whenever you want a check. It scans the grid and tells you one of three things: that there are duplicates, that there are no duplicates but empty cells remain, or that you have finished. Squares involved in a duplicate are highlighted so you can see exactly which pair of digits is in conflict.

Note that the checker only looks for repeated digits - it does not tell you whether a legal-looking digit is the correct one for the final solution. A grid can be entirely free of duplicates and still be wrong, so treat a clean check as evidence that you have not broken a rule yet rather than confirmation that you are on the solution path.

Controls

  • Click / tap a cell — select an empty square
  • Number keys 1-9 — enter a digit into the selected square
  • Backspace / Delete — clear a digit you entered
  • How am I going? — check the grid for duplicate digits

Tips to Master Sudoku

The instinct is to pick a blank square and ask what could go there, which on a grid with 46 blanks gives you far too many candidates to hold in your head. The faster approach reverses it: take a digit, look at the three boxes in a band, and ask where that digit can still legally go. Rows and columns that already contain it eliminate most positions immediately, and often only one square survives.

Scan bands and stacks, not the whole grid

A nine-by-nine grid is really three horizontal bands and three vertical stacks of three boxes each. Because a digit must appear exactly once in each box of a band, placing it in two boxes of that band usually forces its position in the third. Working band by band rather than sweeping the whole grid is what turns a puzzle that looks intimidating into a sequence of small, closed questions.

One fixed puzzle, which changes how you use it

This version serves a single hand-placed grid rather than generating a new one each visit, so refreshing gives you the same 35 clues again. That makes it a poor choice for daily practice but a good one for learning technique, since you can abandon a half-finished attempt, come back later, and work the same position again with a different method to see which approach actually cracks it faster.
