Instructions

Click or tap to drop the currently swinging block onto the top of your tower; every drop costs 1 of your starting 3 HP regardless of how well it lands, and the run ends once HP reaches zero.

A successfully stacked block scores 25 points and counts as a new floor, but a Perfect placement (landing exactly aligned with the block below) scores 50 points instead — double the standard rate for the same single drop.

Consecutive Perfect placements build a bonus: the first Perfect scores 50, a second consecutive Perfect scores 75, a third scores 100, and so on, adding 25 points for each additional Perfect in a row.

Controls

  • Mouse / Tap — stack platforms at the right moment
  • Space — slow down block speed
  • R — retry instantly after falls

Tips to Master Tower Master

Because every dropped block costs 1 HP whether it lands as a Perfect, a standard Success, or knocks the tower off balance, each attempt is inherently limited to 3 total drops — treating every single drop as a scoring opportunity worth optimizing for Perfect placement matters more than just trying to survive as many drops as possible.

Consecutive Perfects are worth chasing over isolated ones

Since each additional consecutive Perfect adds another 25 points on top of the last (50, then 75, then 100, and so on), a streak of several Perfects in a row is worth dramatically more than the same number of Perfects broken up by ordinary Success placements — protecting an active Perfect streak is worth being more cautious on a marginal drop.

Only 3 HP means every drop should aim for Perfect, not just Success

Because the run only allows 3 total block drops before ending, and a Perfect scores double a standard Success on the same drop, aiming for precise alignment on every single placement extracts far more score from the same limited number of drops than accepting an easier, looser Success each time.
