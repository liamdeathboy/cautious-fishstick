Tips to Master Temple Run 2

How to play Temple Run 2?

Use the arrow keys to control your character. Swipe left or right to turn, swipe up to jump, and swipe down to slide. Collect coins and power-ups to boost your score.

Who created Temple Run 2?

Temple Run 2 was created by Imangi Studios.

Is Temple Run 2 free and unblocked?

Yes, Temple Run 2 is free to play and can be accessed on various platforms.

Is Temple Run 2 safe to run on school laptops?

Yes—Temple Run 2 loads locally and stores nothing beyond basic progress. A screenshot of the final score is all that’s needed.
