Instructions

Use the arrow keys or WASD to roll the block; rolling it sideways along one axis flips it onto its long edge covering two tiles, while rolling it the other way tips it end over end, and only a block currently standing upright fits into the single-tile exit hole.

Some levels include bracket-shaped switch tiles that split the block into two separate 1x1 cubes; once split, Space switches control between the two halves, and pushing them back together on adjacent tiles rejoins them into the original block.

Standing the block on certain colored or fragile tiles while it is lying flat (covering two tiles) can trigger a fall through the floor that a block standing upright on the same tile would survive, so tile type has to be checked against the block's current orientation, not just its position.

Controls

  • Arrow keys — roll the block around the platform
  • Space — switch between linked blocks when available
  • R — restart the current level

Tips to Master Bloxors

Because some floor tiles react differently depending on whether the block is standing upright (one tile) or lying flat (two tiles), the same tile can be perfectly safe in one orientation and cause a fall in the other — checking the block's current orientation against the tile it is about to occupy matters as much as the destination itself.

Splitting trades single-cube flexibility for coordination complexity

Since a split block becomes two independently controlled 1x1 cubes switched between with Space, splitting opens up narrower paths neither half of the whole block could otherwise cross, but it also means both cubes need to be walked separately to a spot where they can rejoin — a level with a split switch usually expects this two-phase movement rather than avoiding the split.

The exit only accepts one specific orientation

Because the exit hole is exactly one tile wide, arriving at it with the block lying flat does not complete the level even if the block is technically on the right tile — the final approach to any exit has to end with the block rotated upright, which sometimes requires an extra rotation planned several moves in advance.
