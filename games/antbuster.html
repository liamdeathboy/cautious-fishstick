Instructions

Click the cannon button (hotkey 0) and place a cannon anywhere in the picnic field using the mouse; unlike many tower defense games, cannons here are not restricted to a fixed maze-like path, so placement is comparatively flexible.

Select an upgrade for a placed cannon from the bottom bar using hotkeys 1, 2, or 3; with more than 50 upgrade types available across the game, trying different upgrade combinations on different cannons produces different defensive setups worth experimenting with.

Press P to pause and S to cycle through music-and-sounds, sounds-only, and mute audio settings, useful for pausing mid-level to plan cannon placement or upgrades without ants continuing to advance while you decide.

Tips to Master Antbuster

Because ants move erratically rather than along one fixed path the way many tower defense games script their enemies, concentrating cannons into a single maze-like chokepoint is less effective here than spreading cannon coverage across more of the field to catch ants regardless of which unpredictable route they take.

Fifty-plus upgrades reward experimentation over a single build

Since the game offers more than 50 upgrade types rather than a small fixed set, settling on one upgrade combination early and repeating it on every cannon misses potential synergies — testing different upgrade combinations across different cannons is part of how the game is meant to be explored rather than optimized around one known-best build.

Pausing is a planning tool, not just a break

Because pressing P pauses the game entirely while still allowing menu interaction, using pause deliberately to plan cannon placement or reconsider upgrades — rather than only pausing to step away — lets you make placement decisions without the pressure of ants continuing to advance in real time.
